## Potential Structure

Although the repo is currently bare, here’s what I envision for its future structure:

```

  /raw             # Original, untouched data files
  /processed       # Cleaned or modified datasets
/scripts           # Your go-to scripts for analysis
/README.md        # Documentation for future reference
```

### Directory Breakdown:

- **/data/raw**: For storing your original files. Keep these as backups!
- **/data/processed**: This is where the magic happens. Store your cleaned data here for analysis.
- **/scripts**: A folder dedicated to all the scripts you'll write. This is where you'll spend most of your time.
